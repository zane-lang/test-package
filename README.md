# test-package

A small package once used to try out how the `zane` command fetches and links
dependencies, with prebuilt libraries for three platforms in `build/`.

> **Status:** not maintained (last changed in May 2026). Its source is written
> in an early form of the language that the current compiler does not accept,
> so it is **not an example to learn from**, and **newcomers can skip this
> repository**. Start at [`zane-lang/zane`](https://github.com/zane-lang/zane);
> the [`core` tests](https://github.com/zane-lang/core/tree/main/test/core)
> are working Zane code.
